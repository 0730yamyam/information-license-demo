情報免許証・地震画像比較デモ 更新版

GitHub Pages更新手順
1. ZIPを展開する
2. GitHubで information-license-demo リポジトリを開く
3. Add file → Upload files（または uploading an existing file）を選ぶ
4. index.html をアップロードし、Commit changes を押す
5. 数分待って公開ページを再読み込みする
